# Amuze landscaper template

Website template for a landscaping company that shows off its finished work to homeowners who want their yard done (example business: Cedar & Pine Landscaping, fictional).

- `index.html`: the whole page (HTML, CSS and JS in one file). Edit the BIZ config block at the top of the script to swap business details; look for `EDIT:` comments for copy, photos and sections.
- Hero: photo background with a green gradient overlay, plus a project showcase (featured photo that crossfades through recent projects, with thumbnails). Swap in real project photos at `img/show-*.webp`.
- Recent work gallery: `img/work-*.webp`.
- `img/`: compressed WebP photos. The green tint is applied in CSS, so replacement photos pick it up automatically.
- `favicon.svg` / `favicon.ico` / `favicon-32.png` / `apple-touch-icon.png`: green tree mark matching the logo.
- `PHOTO-CREDITS.md`: source page and photographer for every photo (Unsplash License).
